# ポケモンタイプ相性検索（poketype-checker）

ポケモン本家・Pokémon GO の両方に対応した、弱点タイプ・耐性・おすすめ技・定番ポケモンを素早く調べられる Web アプリです。

## 主な機能

- **ポケモン名 / 図鑑番号検索**: 日本語（ひらがな・カタカナ）・英語・図鑑番号（全角数字含む）で検索可能。メガシンカ・リージョンフォーム（アローラ / ガラル / ヒスイ / パルデア）の検索およびワンクリック切替にも対応
- **タイプ直接選択**: 18タイプから最大2つを選択して単タイプ／複合タイプの相性を即時計算
- **本家 / Pokémon GO モード切替**:
  - 本家モード：4倍 / 2倍 / 0.5倍 / 0.25倍 / 0倍（無効）＆ 6種族値表示
  - Pokémon GO モード：2.56倍 / 1.6倍 / 0.63倍 / 0.39倍 ＆ GO 種族値（HP / 攻撃 / 防御）表示
- **おすすめ技 & タイプ別定番ポケモン**: 弱点タイプに応じたおすすめ技と、ワンクリックで再検索できる定番ポケモン一覧を表示
- **URL クエリ同期**: 検索条件やモード（`?pokemon=`, `?types=`, `?mode=go`）を URL に反映し、履歴操作や共有に対応

## 技術スタック

- Next.js (App Router) / React / TypeScript
- Tailwind CSS v4
- PokeAPI (REST API & GraphQL API)

## 開発コマンド

```bash
npm install
npm run dev      # 開発サーバー起動 (http://localhost:3000)
npm run lint     # ESLint 実行
npm run build    # 本番ビルド
```
